## 🔬 What I'm exploring

* **Adaptive AI**: when should a system retrieve more evidence, spend more compute, or stop?
* **Evaluation**: how do we test systems on realistic tasks and consequential errors?
* **Research systems**: how can models move beyond retrieval while preserving evidence and provenance?
* **Interactive explanation**: how can complex systems become easier to inspect and understand?

> I learn mostly by building: **reproduce → adapt → break → understand → rebuild.**
